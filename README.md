# Transcript Studio

Transforme vídeos do YouTube, TikTok, Instagram e X — ou arquivos do seu computador — em texto. As legendas da plataforma são usadas quando existem; quando não existem, a transcrição é feita localmente com IA (Whisper), na GPU NVIDIA ou no processador.

## Download

Baixe o instalador **Transcript-Studio-Setup-x.y.z.exe** na [última versão](../../releases/latest).

- Windows 10/11 64 bits
- O Windows SmartScreen pode exibir um aviso na primeira execução (o instalador ainda não é assinado digitalmente): clique em **Mais informações → Executar assim mesmo**.
- O aplicativo se atualiza sozinho quando uma nova versão é publicada aqui.

Este repositório contém apenas os instaladores publicados.
